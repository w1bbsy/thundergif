# 09: Keyboard use

**What to build:** A user can use the Picker entirely from the keyboard: focus starts in the search box, Tab or arrow keys move into and through the results, Enter inserts the focused GIF, and Escape closes the Picker.

**Blocked by:** 02 (Search with More)

**Status:** ready-for-agent

- [ ] Search box is focused on open
- [ ] Keyboard moves focus from the search box into the results grid and between tiles
- [ ] Enter on a focused tile inserts that GIF
- [ ] Escape closes the Picker
- [ ] Focused tile is visibly highlighted
- [ ] Tiles expose the GIF description to screen readers
- [ ] Automated tests through the one seam cover keyboard movement and insertion
