# Thundergif

Thunderbird add-on for searching KLIPY or GIPHY and inserting a GIF into an email. Vocabulary: `GLOSSARY.md`. Decisions and status: `Project Context.md`. v1 spec: `docs/spec.md`.

## Agent skills

Issues live in GitHub Issues for w1bbsy/thundergif, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
