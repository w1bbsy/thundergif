Show GIFs while you write

Thunderbird blocks images from other servers while you write, so a GIF shows as a blank box. Your recipients see it either way. To see GIFs while writing, allow the server each Provider's GIFs come from:

  1. In Thunderbird, open Settings > Privacy & Security.
  2. Under Email content, click Exceptions.
  3. Paste an address below into Address of web site, click Allow, then Save Changes.

    An exception also lets images from that server load in emails you receive.

    Thundergif Live, an edition that shows GIFs while you write, is available from the project's GitHub page. It needs extra permissions, so it is not listed on addons.thunderbird.net.

    What Thundergif sends

    Your search terms and Provider key go only to the Provider you are searching (GIPHY or KLIPY). GIF images load from that Provider's servers. Your keys, Rating and Favourites stay in Thunderbird on this computer. Thundergif sends no analytics.
