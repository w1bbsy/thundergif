# Thundergif 1.2.2

Thundergif Live now works with Thunderbird 160. No other changes.

Thunderbird switches Thundergif Live off when it updates to a version newer than Live has been tested on. If you saw "Thundergif Live is incompatible with Thunderbird 160.0", install `thundergif-live-1.2.2.xpi` below to turn it back on. Your keys, settings, and Favourites are kept.

Thundergif (the addons.thunderbird.net edition) was not affected, as it has no version limit. `thundergif-1.2.2.xpi` is included below so both editions share the version number, but it is otherwise the same as 1.2.1.

Install: download the file, then in Thunderbird open Tools > Add-ons and Themes > gear icon > Install Add-on From File.
