# Thundergif 1.1.1

Works with Thunderbird 159. No other changes.

Thunderbird switches Thundergif off when it updates to a version newer than Thundergif has been tested on. If you saw "Thundergif is incompatible with Thunderbird 159.0", this update turns it back on.

Install: download `thundergif-1.1.1.xpi` below, then in Thunderbird open Tools > Add-ons and Themes > gear icon > Install Add-on From File. Or get it from addons.thunderbird.net once approved.
