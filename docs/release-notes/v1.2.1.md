# Thundergif 1.2.1

A shorter install prompt. Thundergif now asks for access to four GIPHY and KLIPY servers instead of 12: the two search services and the one GIF server each Provider's GIFs are inserted from. Previews in the GIF picker still load from the Providers' other servers, which needs no permission.

Nothing else changes. Updating from 1.2.0 needs no new permissions, so Thunderbird will not ask you anything.

## Install

- **Thundergif:** from addons.thunderbird.net once approved, or download `thundergif-1.2.1.xpi` below.
- **Thundergif Live:** download `thundergif-live-1.2.1.xpi` below.

Then in Thunderbird open Tools > Add-ons and Themes > gear icon > Install Add-on From File.
