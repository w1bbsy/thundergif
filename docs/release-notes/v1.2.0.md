# Thundergif 1.2.0

Thundergif now comes in two editions, built from the same code. Both are attached below.

| | Thundergif | Thundergif Live |
|---|---|---|
| File | `thundergif-1.2.0.xpi` (also on addons.thunderbird.net, once approved) | `thundergif-live-1.2.0.xpi` |
| GIFs while you write | A blank box, unless you allow two addresses in Thunderbird's settings | Shown straight away |
| Install warning | None | "Full, unrestricted access" |
| New Thunderbird versions | Keeps working | Needs an update for each new major version (tested up to 159) |

Your recipients see the GIF in both. Why two editions: addons.thunderbird.net is not accepting new add-ons with a Thunderbird Experiment until at least 2027, and showing GIFs while you write needs one. Thundergif Live keeps it; Thundergif drops it so it can be listed.

## If you have 1.1.1 or earlier installed

Remove it before installing 1.2.0: Tools > Add-ons and Themes > Thundergif > Remove. Then install the edition you want.

- Removing it deletes your saved Provider keys and Favourites. Copy your keys somewhere first; you can also find them again on GIPHY's or KLIPY's developer site.
- If you keep 1.1.1 instead, Thunderbird may later replace it with Thundergif from addons.thunderbird.net, and GIFs would stop showing while you write.

## New

- Thundergif (without Live) shows a notice the first time you open the GIF picker, explaining the blank box. Dismiss it and it stays gone.
- Its settings page has a "Show GIFs while you write" section: where to go in Thunderbird (Settings > Privacy & Security > Email content > Exceptions), the two addresses to allow, each with a Copy button, and a link to Thundergif Live.
- Both editions now insert every GIF from one server per Provider (`media.giphy.com` and `static.klipy.com`), which is what makes two addresses enough. The GIFs are the same files as before.

## Install

- **Thundergif:** from addons.thunderbird.net once approved, or download `thundergif-1.2.0.xpi` below.
- **Thundergif Live:** download `thundergif-live-1.2.0.xpi` below.

Then in Thunderbird open Tools > Add-ons and Themes > gear icon > Install Add-on From File.
