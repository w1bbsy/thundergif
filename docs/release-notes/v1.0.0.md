# Thundergif 1.0.0

The first release. Search GIPHY or KLIPY from Thunderbird's compose window and drop a GIF into your email.

## What's in it

- GIF button on the compose toolbar, opening a picker with trending GIFs and search (as you type, 24 at a time, More for the next 24).
- GIPHY and KLIPY, each with your own free key; switch between them in the picker.
- Favourites, kept per Provider on your computer.
- Rating setting (G, PG, PG-13, R).
- Plain-text emails get the GIF's link instead of an image.
- Keyboard use throughout.
- Settings check each new key and say whether it works.

## Good to know

- Thunderbird warns that the add-on has "full, unrestricted access". That comes from one small module that lets your draft show the GIF, doing what Insert > Image does. The README explains it in full.
- GIFs are sent as links, so some recipients will need to allow remote images to see them.
- Free Provider keys allow about 100 requests an hour.

## Install

Download `thundergif-1.0.0.xpi` below, then in Thunderbird open Tools > Add-ons and Themes > gear icon > Install Add-on From File. Thundergif installs on Thunderbird 140 or later; it has been tested on Thunderbird 158 on macOS only.
